# raiokiuai — Branding website

Marketing site for **raiokiuai**: conversational AI agents that talk, and visual workflows that act. Ship to WhatsApp, web, app and voice.

This repo is a single static page (`index.html`) with no build step.

## Preview locally

```bash
python3 -m http.server 8000
# open http://localhost:8000
```

## Deploy

Any static host works (Vercel, Netlify, Cloudflare Pages, GitHub Pages). Point it at the repo root and serve `index.html`.
