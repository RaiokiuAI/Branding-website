How it works

Build the action. Give it a voice. Ship it everywhere.

Flows are the hands, and agents are the conversation. Together they turn a customer's message into a real booking, offer or refund.

Agents

A complete agent stack, without the plumbing.

We take care of memory, tools, concurrency, multimodal input and safety limits, so your team can focus on the customer journey.

Prompt studio

Generate a system prompt from a use case, refine it against templates, then apply it to the agent in one click. Dynamic variables personalise every turn.

Tools from anything

  • API tools from a pasted cURL
  • Flows attached as tools
  • Knowledge bases (RAG)
  • CRM events & structured replies

Secrets stay secret

Parameters can come from the LLM, session variables, encrypted team secrets or system values, and the model never sees a key.

Memory that lasts

Persistent checkpoints keep a conversation going for weeks. Rolling summaries and history compaction keep very long WhatsApp threads fast.

Multimodal by default

Customers can send photos, voice notes and documents. Audio is transcribed and everything is passed to vision-capable models.

Engagement on autopilot

  • LLM-timed nudges for idle chats
  • Follow-up suggestion chips
  • CRM messages injected into live chats
  • One-tap "call me back" requests

Structured responses

JSON-Schema output, carousels, CTAs and quick replies, so agents send UI instead of walls of text.

Never leaves you hanging

If a customer double-texts, the newer message replaces the in-flight run. A slow turn still gets a graceful answer built from partial context.

Multi-agent orchestrator

One front door. Many specialist agents.

The orchestrator puts a single router in front of your agents. It sends each query to the right specialist, or plans a multi-agent answer.

  • RouterClassifies each query as greeting, single agent or complex, and routes by business unit.
  • PlannerBuilds a parallel or sequential plan across agents.
  • AgentsEach step runs on an agent with its own tools and memory.
  • SynthesisMerges the results into one coherent reply.
